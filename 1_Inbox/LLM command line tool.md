[LLM: A CLI utility and Python library for interacting with Large Language Models](https://llm.datasette.io/en/stable/)

`llm` is a tool that enables access to large language models from terminal, making it easy to embed it to shell-based workflows.

## Showing all models

To show all models llm has access to via ollama
`llm ollama list-models`

The same for openai
`llm openai models`
